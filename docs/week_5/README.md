# Uke 5 - Forms og data validering

Denne uken ser vi på hvordan vi kan bruke [forms](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/form) til å sende data fra nettsiden vår til enten vår egen server, eller til andre steder. Vi kommer til å fokusere på hvordan vi bruker forms sammen med React og React Router og hva forskjellen er mellom klient og server form submissions.
